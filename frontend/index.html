RESEARCH MATERIALS

Choices made
for this study.

The completed pilot uses Roman-script Hinglish translations of English news articles. Prior Hindi-script resources remain background; this small AI-screened sample is exploratory.

01 / DATASET

XL-Sum Hindi

A Hindi news summarization test set gives the baseline aligned source and reference summaries for a paired comparison.

Hasan et al. · Findings ACL 2021 ↗
02 / BASELINE

mT5 multilingual XLSum

A multilingual summarizer fine-tuned for XL-Sum provides a reproducible Hindi baseline. It is not a new model developed in this project.

Checkpoint model card ↗
03 / FINAL PILOT DATA

News_Hinglish_English

Public English/Romanized-Hinglish news pairs support a 30-source pilot. The Hinglish side is machine-generated and curated; it is not naturally authored, and the corpus has no gold summaries.

Dataset card ↗
